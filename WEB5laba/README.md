# Лабораторна робота №5

Кожне завдання – в окремій папці (у кожному завданні свій `style.css`).

- `task1/` – дворівневий список (потрібна папка `icons/` з іконками)
- `task2/` – таблиця (без класів та id)
- `task3/` – стилізація форми анкети з ЛР №3
- `task4/` – 4 блоки з градієнтними фонами
- `task5/` – box-sizing, overflow, display
- `task6/` – сайт-візитівка з фоновими зображеннями (`img/`)
